# 中華まん製造最適化シミュレーター（試作）

コンビニの中華まんについて、需要の変動・製造リードタイム・販売期限・ショーケース容量を考慮し、製造タイミングと数量を検討する個人学習プロジェクトです。

> **注意**: 実店舗の販売データは使用していません。需要パターン、気温・曜日・降雨の係数、損失単価はすべて仮定です。店舗での効果・精度を実証したものではなく、実運用にそのまま使うことは想定していません。

## ファイル

- `nikuman_optimizer.py`: 気温・曜日・降雨・在庫などの入力条件から、30分ごとに製造数を近似的に提案するモデル
- `nikuman_simulator.py`: 固定製造と簡易的な調整製造を仮想需要で比較するシミュレーター

## 実行方法

Python 3.9以上を想定。外部ライブラリは不要です。

```bash
python nikuman_optimizer.py
python nikuman_simulator.py
```

Windowsで `python` が使えない場合は `py nikuman_optimizer.py` を試してください。

## 条件を変更する

`nikuman_optimizer.py` の先頭にある「入力設定」を編集します。

| 変数 | 意味 |
|---|---|
| `TEMPERATURE_C` | 最高気温（℃） |
| `DAY_OF_WEEK` | 曜日（`'月'`〜`'日'`） |
| `RAIN` | 降雨の有無（`True` / `False`） |
| `CAPACITY` | ショーケース容量 |
| `INITIAL_STOCK` | 7:00時点の完成済み在庫数 |
| `INITIAL_REMAINING_MIN` | 初期在庫の残り販売可能時間（分） |
| `WASTE_COST` | 廃棄1個の仮の損失 |
| `STOCKOUT_COST` | 欠品1個の仮の機会損失 |
| `BASE_HOURLY` | 7:00〜翌2:00の時間帯別基本需要（19個の値） |

## モデルの前提

- 製造開始は7:00〜18:00（18:00開始分は18:50に完成）
- 製造所要時間50分
- 完成後430分で販売期限
- ショーケース容量は初期値18個
- 10分刻みで在庫・販売を追跡し、30分刻みで製造判断
- 18:00以降も期限内の商品は販売する想定
- 欠品と廃棄のコストを考慮する**近似的・局所的な製造数選択**であり、全日を通じた厳密最適化ではありません
